# RobStride Console · RS05 双电机图形化上位机

当前单文件 EXE 与相邻 FreeRTOS 工程的 **480 MHz 固件**匹配，已完成双电机同时运行、独立停止、OLED 和灯效回归。实测依据见 [480 MHz 配置与回归](../../RobStride05_H743/Docs/12_480MHz性能配置与实板回归.md)。保留相邻固件的 AXF 可自动解析当前布局；独立移动 EXE 时使用内置固件档案，连接前同样核对板上 Flash。

## WS2812 灯带控制（2026-10-26）

新版 EXE 左侧增加“灯带控制”：7 种灯效、RGB 颜色、亮度、动画速度、开关，以及最多 8 项的自定义循环列表（排序、重复项、每项 1–600 秒）。点击应用后才下发；固件整组校验并返回回执。循环由 MCU 执行，断开上位机后继续；可在当前浏览器保存/读取方案，MCU 重启恢复默认。此功能无需使能电机。详细说明见 `../../RobStride05_H743/Docs/11_WS2812上位机自定义灯效.md`。

参考 Trae 官网的黑色底色、荧光绿、细线面板和工作台布局。所有资源均在本地，运行时不依赖 CDN，也不上传数据。

## 双电机版（2026-10-26）

最终程序为本目录上一级 `RobStrideConsole.exe`。原电机 ID 127、新增电机 ID 126 已实板配置、重上电确认，两台同时在线。双击程序后选探针连接，按需先核对双电机身份，再分别选择上方卡片执行准备、使能和运行。每台参数、目标、回执独立，曲线/测量/诊断跟随选中电机。顶部“全部失能”或 Esc 操作两台；选中电机失能仅操作当前一台。控制仍为速度模式。

本轮已用此单文件 EXE 实测单台正反转、双台 +5/-5 rad/s、仅停止一台而另一台保持 +2 rad/s，最终两台失能。CSV 增加 motor/motor_id。详见 [固件双电机使用与实测](../../RobStride05_H743/Docs/10_双电机独立控制与实测.md)。

MCU 重启后需在首次接入入口确认两台身份；已改好 ID，直接核对即可，无需再改 ID。源码仍兼容匹配 AXF 的旧 HAL 单电机工程，但它只提供一台通道。

以下启动方式适用于原有目录打包版和源码：

推荐双击 **启动上位机.cmd**。已有打包版本时会启动 `dist/RobStrideConsole/RobStrideConsole.exe`，并打开默认浏览器；否则使用本机 Python 运行源码。

也可直接双击 `dist/RobStrideConsole/RobStrideConsole.exe`。打包程序不需要安装 Python；移动时必须保留整个 `RobStrideConsole` 文件夹及 `_internal`，不能只复制 EXE。

页面地址：<http://127.0.0.1:8765>。窗口为本机浏览器界面，真实硬件通信由本地 Python/EXE 服务完成，不是独立串口程序。

结束使用时点击左下角 **退出 ⏻**，会先请求失能并释放探针，再关闭本地服务。仅关闭浏览器标签页不会停止运动；后台服务保留，可重新打开页面控制。

## 硬件路径与连接

**PC USB → 现有 Horco CMSIS-DAP / ST-Link → SWD → STM32H743 → 现有 CAN 收发器 → RS05。**

复用 `RobStride05_H743_HAL/App/app_debug.h` 中的 `g_debug`。当前固件没有 UART/USB CDC 上位机协议，因此这里不使用 COM5。本次已更新并下载匹配固件，增加参数兼容诊断。

1. 使用当前已经下载、能正常运行的固件。在 Keil 内确认 CPU 为 Run，然后退出 Debug，释放调试器。不得同时用 Keil Watch 修改命令区。
2. 启动上位机，刷新并选择调试器，点击连接。
3. 后台从工程 AXF 的 DWARF 自动解析变量地址与字段布局，核对板上完整 Flash 加载段；不一致则拒绝连接。不会复位、烧录、暂停或自动启动 CPU。当前同时支持两个工程：`RobStride05_H743`（FreeRTOS 版）与 `RobStride05_H743_HAL`（单线程版），启动时列出附近所有候选 AXF（新的在前），连接时按板上 Flash 自动选中并做整段比对；日志会显示 `Flash 一致 · 工程名`。也可用 `--axf` 指定唯一 AXF。
4. H743 已连接与电机在线是两个状态。只有新鲜且一致的电机反馈才能显示有效测量；CAN TX ACK 不等于电机在线。

若修改了固件，请重新编译并使用与板上固件匹配的 AXF。源码会自动读取相邻工程的当前 AXF。打包版在本目录结构下也优先读取相邻工程；独立移动后则使用打包时生成的 `firmware_profile.json`，需要重新打包才能更新。

## 控制顺序

当前工程只实现**速度控制**。位置和力矩显示为反馈，不提供位置模式、力矩模式、设零或持久参数写入。

1. 固定电机、空载，确认接线、供电和可切断电源，勾选界面确认框。
2. 设置速度上限、相电流限制、加速度，点击 **准备**。默认 `33 rad/s / 2.4 A / 20 rad/s²`：速度模式可调至 `±33 rad/s`（约 `±315.13 rpm`），相电流可设至 RS05 最大 `11 A`，加速度可设至参数表上限 `150 rad/s²`。2.4 A 为额定相电流，20 rad/s² 为手册加速度默认值。速度上限可自行调低；所有值不再共用 0.5 的联调限制。
3. 等待日志记录对应序号完成、状态准备就绪。若出现旧固件兼容提示，请先阅读并勾选兼容确认，再点击 **使能**。准备与使能命令强制零目标；编辑框里的非零速度不会提前执行。
4. 设置目标速度，点击 **运行**。默认目标 `1 rad/s`（约 `9.55 rpm`）；正数正转、负数反转。滑块、正反转预设和数字输入只编辑目标，必须点击运行才会提交。支持 rad/s 与 rpm 显示转换，单位切换保留同一个目标，两个方向均可调到范围端点。
5. **持续运行**：一次 RUN 指令在 H743 中保持，直到停止、失能或故障；不设运行时长，不需要定时续发。使能后也不再有 5 秒操作窗口。修改输入后点击「应用新速度」才生效。页面关闭、隐藏或暂停轮询不会撤销目标；故障后不会自动恢复运动。
6. **减速停止**：以已准备的加速度降到零，保持使能。**立即失能 / Esc**：提交失能请求，可覆盖处理中命令；并不保证机械锁止，也不等于物理急停。
7. 修改限制时先失能，再准备。清错在通信诊断页，请先排除原因；程序不会自动恢复运动。

## 参数兼容与本次修复

速度范围依据 RS05 使用说明书 261009 第 37 页：当前采用的速度模式 `spd_ref 0x700A` 明示 `−33～+33 rad/s`。第 6 页标注的 480 rpm±10% 是额定 48 V 下的空载规格，第 32～33 页的 ±50 rad/s 是运控/反馈的编码量程；软件采用当前控制模式明确给出的指令上界。实际达到的速度还取决于母线电压、负载和所设相电流。官方 SampleProgram 的速度控制流程为模式 2 → 使能 → 设置 0x7018/0x7022 → 写 0x700A，但其 RS01 的 44 rad/s 量程不适用于 RS05。

实板电机版本返回 0x00050003。旧版本上位机将电机明确拒绝 0x7022（加速度）和 0x7028（通信超时）统一报为「参数读回不符/超时」，导致准备失败。新版在明确拒绝时尝试手册旧地址 0x201E / 0x200C；本电机也拒绝这些地址，因此采用明确标注的兼容状态。加速度由 H743 已有 20 ms 速度斜坡执行，界面不再虚报电机侧 250 ms 超时。使能前须单独确认此限制。模式、零速、电流限制仍严格读回核对；回复丢失、数值不符仍报错。

诊断页新增具体参数索引、期望值、实际值、拒绝/不符/超时原因及兼容能力。连接频率改为已实测的 SWD 1 MHz；连接异常会释放会话，需显式重连。释放 SWD 会话本身不会撤销 H743 中已下发的速度。

## 数据与保护

- 目标/斜坡后目标、实际速度、位置、力矩、温度、Iq、电压，最近 30 秒曲线，可切换观测项。显示暂停只冻结曲线，后台仍采集和执行固件保护。
- CSV 导出最近最多 36000 个一致快照，包含时间、MCU tick、online、状态、目标与实测值、电流/电压年龄。离线时原始保留值供排查，分析时必须过滤 `online=0`，并检查 `current_age_ms`、`voltage_age_ms`。
- `MotorStatus` 的连续控制/测量区（当前 148 字节，含命令回执、状态、反馈、限制、健康位和发布时间）使用固件发布序号校验，读前后的序号必须相同且为偶数。遥测每 20 ms 发布一次，电机控制与保护仍每个服务周期执行，避免 USB 读取跨越 1 ms 发布周期而反复失败。后台按 MCU 时间补偿发布到读取结束的年龄，再加上 HTTP 快照年龄使数据失效。偶尔获取失败时保留上次一致快照；运动命令重新获取一致快照，失败则拒绝。CAN 计数、身份信息、OLED、系统与命令区是独立采样，不承诺整组原子快照；控制校验不依赖这些独立诊断字段。
- 普通控制写入对应 `g_debug.cmd` 或 `cmd2`，首次配置写 `setup` 的主机字段，全停写 `stop_all_seq`；，遵守“奇数 → 完整参数 → 读回核对 → 新偶数最后提交”。界面提交成功只表示写入完成；日志会继续等待 `executed_seq/result`，不会把请求当作电机动作完成。
- 页面轮询仅用于显示数据，不控制运行授权。主动点击断开或退出会先请求失能再释放探针，断开后无法继续确认物理状态。
- 若本地服务被强制关闭或 USB/探针突然断开，H743 中的速度指令仍可能持续有效，需重新连接后停止或直接断电。**本次实测该电机拒绝 0x7028 / 0x200C，未验证电机侧 CAN 断线自停；CAN 线断开或 MCU 停止运行时不能承诺自动停机，必须保留可直接切断电源的手段。**
- 本地服务仅绑定 `127.0.0.1`，写 API 校验 Host、Origin 和随机会话令牌，拒绝普通跨站请求。不要将服务转发到公网。
